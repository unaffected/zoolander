# Zoolander

A desktop app for modeling data and working with it in one place. Design resources and
their relations on a visual canvas, then enter records through forms generated from the
model. Everything is stored locally on your machine.

## Features

- Visual modeling — resources, fields, relations, auto-layout
- Data entry — forms generated from the model, no form building
- Import / export — JSON Schema in, model and data out
- Local — no account, no cloud, no setup

## Install

Build from source. Requires [Bun](https://bun.sh).

```sh
bun install
bun run dist
```

The installer for your platform lands in `release/`. Run it, then launch Zoolander.
